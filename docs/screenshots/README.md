# Portfolio Screenshot Checklist

Use genuine captures of the running storefront. Do not add mockups or placeholder images. Capture at the listed viewport sizes, use representative product data, and avoid including personal information.

## Recommended captures

- [ ] `homepage-desktop.png` - homepage at 1440px wide.
- [ ] `homepage-mobile.png` - homepage at 390px wide.
- [ ] `shop-desktop.png` - shop listing with product cards visible.
- [ ] `product-details-desktop.png` - product gallery and product options.
- [ ] `cart-desktop.png` - cart with at least one representative item.
- [ ] `checkout-desktop.png` - checkout form and order summary with test-only details.
- [ ] `wishlist-desktop.png` - wishlist with at least one saved item.
- [ ] `mobile-navigation.png` - open mobile menu at 390px wide.

## Capture notes

1. Start the site using the local instructions in the root [README](../../README.md).
2. Set the browser viewport to the recommended width and capture the actual page.
3. Use the storefront to add test products to the cart or wishlist where needed.
4. Keep test contact details fictional and do not capture real customer data.
5. Save final image files in this folder using the names above, then mark the matching items complete.

The browser preview has been visually spot-checked. Screenshot capture was available, but this shared browser exported images with viewport margins that did not match the page dimensions, so those unsuitable exports were removed and no screenshot files are included yet.
